# OCI — Docker Compose to Kubernetes/Podman

## Input

`compose.yml` — Docker Compose file with `${VARIABLE}` placeholders.

## Prerequisites

- [kompose](https://kompose.io/) — converts compose.yml to a Helm chart
- [helm](https://helm.sh/) — renders the Helm chart to Kubernetes YAML
- [podman](https://podman.io/) — runs the Kubernetes YAML locally

## Usage

```bash
# Generate Helm chart and podman-ready YAML
./compose2kube.sh

# Run the stack locally with podman
podman play kube kube/podman.yml
```

## Outputs (all inside `kube/`)

| File | Description |
|---|---|
| `kube/.env` | Auto-generated on first run with default values (edit before re-running) |
| `kube/helm/` | Helm chart generated by kompose |
| `kube/podman.yml` | Kubernetes YAML rendered by `helm template`, runnable with `podman play kube` |

## Notes

- All generated files go into `kube/` — the `oci/` directory only contains the source template (`compose.yml`) and the script.
- Edit `kube/.env` to set your project name, ports, and credentials before re-running the script.
- The script sources `kube/.env` before calling kompose so `${VARIABLE}` placeholders in `compose.yml` are resolved.
- If `kube/.env` already exists, it will **not** be overwritten. Delete it to regenerate defaults. |
